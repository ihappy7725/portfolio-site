현재 열린 한정선 베트남 마케팅 대시보드 저장소에서 HOME의 뉴스 탐색 기능을 개선해줘. 계획만 제안하지 말고 기존 코드를 확인한 뒤 구현과 검증까지 진행해줘.

배경
- HOME은 현지 일정, 뉴스와 준비 업무를 모아 마케터의 다음 행동을 돕는 화면이야.
- 현재 탐색용 뉴스와 확인된 규제 및 공지를 구분하고 있어.
- 발표에서 기사 목록을 넘어, 한정선의 베트남 진출에 어떤 의미가 있는지 색상과 그래프로 보여 달라는 피드백을 받았어.
- 뉴스 영향 시각화는 아직 구현하지 않았어.

먼저 AGENTS.md와 README를 읽고 HOME의 검색, 뉴스 렌더링, 번역, 데이터 모델과 API를 찾아줘. 공개 페이지에서는 /home/와 home_main.js가 보이지만 실제 저장소 구조를 확인해서 수정 위치를 결정해줘. 이 작업은 현재 대시보드 저장소에서 진행하고 별도의 개인 포트폴리오 폴더는 수정하지 마.

1. 정보의 확인 상태와 영향 분류를 별도로 유지해줘.
- 기존 탐색 기사와 확인된 공지의 구분을 유지해줘.
- 이번 시각화의 주 대상은 탐색용 뉴스 영역이야.
- 영향 분류나 AI 평가만으로 탐색 기사를 확인된 공지로 승격하지 마.

2. 탐색 기사를 네 가지 영향으로 분류해줘.
- 기회: 초록색
- 주의: 노란색
- 위험: 빨간색
- 판단 보류: 회색
- 기준은 한정선의 베트남 식품 및 디저트 시장 진출과의 관련성이야. 기사 문장의 밝거나 어두운 어조만으로 분류하지 마.
- 각 기사에 영향 분류, 짧은 이유, 관련 주제를 제공해줘. 원문, 출처와 게시일은 유지해줘.
- 자료 부족, 상반된 영향, 적용 대상 불명확, 분류 실패는 판단 보류로 처리해줘.
- 기사 수를 위험의 크기나 시장의 중요도로 표현하지 마.

3. 뉴스 영역 상단에 네 개의 분류 카드와 기사 수 분포를 보여주는 누적 가로 막대를 구현해줘.
- 현재 검색 및 기간 조건에서 확보된 고유 기사만 집계해줘.
- 카드나 막대를 선택하면 아래 기사 목록이 해당 분류로 필터링되고, 전체 보기로 돌아갈 수 있게 해줘.
- 각 카드에는 색상과 함께 분류명, 아이콘과 건수를 표시해줘.
- 그래프에는 기사 수 분포라는 설명을 붙이고, 건수 0, 검색 전, 로딩, 오류와 결과 없음 상태를 구분해줘.
- 색만으로 의미를 전달하지 말고 키보드 조작과 모바일 화면도 지원해줘.
- 기존 디자인과 컴포넌트를 재사용해줘.

4. 분류 구현은 현재 사용 가능한 구성을 활용해줘.
- 기존 뉴스 필드와 저장 구조를 확인하고 필요한 메타데이터만 확장해줘. 기존 출처와 확인 상태를 덮어쓰지 마.
- 기존 AI 연동이 있으면 확인된 설정과 호출 방식을 재사용할 수 있어. AI가 제안한 분류는 분류 제안으로 표시해줘.
- 연동이 없으면 설명 가능한 규칙과 판단 보류를 기본으로 동작하게 해줘. 제목 키워드만으로 실제 규제 적용이나 사업 효과를 확정하지 마.
- 같은 기사 재분류는 가능한 범위에서 캐시하고, 분류 실패 시에도 기존 기사와 원문 링크는 계속 볼 수 있게 해줘.
- 분류 결과의 신뢰도를 임의의 정확도 퍼센트로 표시하지 마.

5. 기존 기능과 언어를 유지해줘.
- 검색, 번역, 원문 이동, 확인된 공지 영역, 캘린더와 업무 관리를 유지해줘.
- 현재 저장소가 지원하는 모든 언어에 새 문구를 함께 추가해줘. 공개 HOME에서 한국어, 영어와 베트남어가 보이므로 실제 언어 구성을 확인해줘.
- 표시 이름의 영문 표기는 Hanjungsun으로 유지해줘. 가운데점 기호는 쓰지 마.

6. 변경에 맞는 검증을 수행해줘.
- 같은 영향 분류를 받아도 탐색 기사와 확인된 공지의 상태가 보존되는지 확인해줘.
- 판단 근거 부족, 상반된 영향과 API 실패가 판단 보류로 처리되는지 확인해줘.
- 중복 기사, 검색 및 기간 필터, 분류별 건수와 표시 목록의 일치 여부를 확인해줘.
- 데스크톱과 모바일 너비 390px에서 카드, 그래프, 원문 링크와 키보드 동작을 확인해줘.
- 테스트용 기사는 실제 운영 뉴스와 구분하고, 기존 데이터는 보존해줘.
- 실제 실행한 검사와 확인하지 못한 항목을 구분해서 알려줘. 분류 정확도나 시간 절감 효과를 검증한 것처럼 쓰지 마.

완료 후 바뀐 동작, 수정 파일, 검증 결과와 남은 설정을 설명해줘. 가능하면 실제 구현 화면도 남겨줘. git commit, push와 배포는 내가 요청할 때만 진행해줘.
